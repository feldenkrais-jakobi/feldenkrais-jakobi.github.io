## Datenschutz

Diese Website erhebt selbst keine personenbezogenen Daten. Eine
Kontaktaufnahme erfolgt über die im Impressum angegebenen Kontaktdaten.

## Hosting über GitHub Pages

Diese Website wird als statische Seite über GitHub Pages gehostet, einen
Dienst der GitHub Inc. (GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco,
CA 94107, USA). Beim Aufruf der Seite speichert GitHub die IP-Adresse des
Besuchers zu Sicherheitszwecken, unabhängig davon, ob der Besucher bei
GitHub angemeldet ist. Nähere Informationen finden Sie in der
Datenschutzerklärung von GitHub:
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement){target="_blank"
rel="noopener"}

Weitere personenbezogene Daten werden durch diese Website selbst nicht
erhoben.

## Ihre Rechte

Auskunft, Berichtigung und Löschung der vom Hosting erhobenen Daten
richten sich an GitHub (siehe oben). Für Fragen zur Website selbst können
Sie sich an die im Impressum angegebene Adresse wenden.
